## 蓝图配置（测试用，已从原始配置修改）

原始配置：标准低光速引擎 / 小型STL罐(1500) / 标准反应堆(2400GW) / 大型FTL罐(2000) / **小型货舱(500t)** / 基础船板(G8) / 整备880t / FTL 3.9pc/h

- 所有数据来自游戏 BTF（蓝图试航模拟）面板，燃料消耗 f 与反应堆使用量 r 均标出。
- 转移/离港/进近距离随轨道运动缓慢漂移（各点间行星位置不同），燃料在距离基础上比较。

## 汇总：载重效应总结

| 项目 | 载重效应 |
|---|---|
| 离港燃料 | ❌ 无关（恒 0.49×罐×f + FTL离港费） |
| 转移燃料 | ❌ 无关（≈2×0.49×罐×min(f,0.5)） |
| 跃迁(FTL) | ❌ 无关 |
| 进近燃料 | ✅ 略增（41→47u） |
| 起飞燃料 | ✅ 强增（39→60u） |
| 着陆燃料 | ✅ 强增（40→66u；VH-192c 27→41u） |
| STL 段耗时 | ✅ 强增（乘性 ~2.4–2.7x @ 3000t，G受限区也已变慢） |
| 着陆/起飞燃料 vs f | ❌ 与 f 无关 |

**关键启示：**
1. 着陆/起飞燃料 = 距离模型(0.455/0.578×√d) + **载重/质量项**（当前模型缺失此载重项 → 高载重低估）
2. STL 段速度（转移/离港/进近）直接随质量/载重变化，**不仅在推力受限区**（600t G受限时已 -18% 速度）→ 现有 (a/G)^0.55 推力修正不足
3. 燃料消耗 f 的转移段饱和在 f≈0.5（标准引擎），非 10.96×flow=0.164
